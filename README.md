# Hiver AI Support Agent

AI customer support agent built for the Hiver SDE Intern take-home assignment.

## Project Goal

Build an AI support agent for one brand that can:

1. Classify incoming customer messages into support intents.
2. Generate responses grounded in historical support conversations.
3. Decide whether a message should be automatically handled or escalated to a human.
4. Evaluate the system using a manually labelled golden dataset.
